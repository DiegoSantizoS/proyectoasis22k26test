3. Benchmarking de Órdenes de compra y recepción de compras

3.1 Objetivo

Comparar cómo los sistemas ERP gestionan el ciclo completo desde la creación de una orden de compra hasta la recepción física de los bienes para Embutidos de Calidad, S.A.

3.2 Creación de órdenes de compra

Los campos principales que el sistema debe registrar son:

  • Número de orden y fecha
  • Proveedor, producto y cantidad
  • Precio, descuento e impuestos
  • Estado de la orden

3.3 Flujo de autorización

El sistema debe soportar un flujo jerárquico: Solicitud -> Orden de compra -> Autorización -> Envío al proveedor.

3.4 Recepción de compras

Al recibir la mercadería en bodega, el sistema debe permitir:

  • Recepción completa del pedido.
  • Recepción parcial, dejando la orden abierta para el saldo pendiente.
  • Manejo de productos rechazados.

3.5 Estados de una orden

Para mantener la trazabilidad, los estados propuestos son:

  1. Creada
  2. Pendiente de autorización
  3. Autorizada
  4. Enviada al proveedor
  5. Parcialmente recibida
  6. Recibida y Cerrada

3.6 Hallazgos principales

Se recomienda implementar aprobaciones por jerarquía, permitir recepciones parciales en bodega y manejar estados claramente definidos para evitar errores o compras no autorizadas.
