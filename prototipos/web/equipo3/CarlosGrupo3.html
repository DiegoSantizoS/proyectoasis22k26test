Cuentas por pagar y programación de pagos

Objetivo

Determinar cómo los sistemas ERP administran las obligaciones financieras generadas por las compras realizadas a proveedores.

El caso establece que después de registrar una compra debe incrementarse la cuenta por pagar correspondiente al proveedor y posteriormente programarse el pago de acuerdo con su vencimiento.

Generación de cuentas por pagar

pUtilizando el flujo presentado por el software de freshbooks se planea implementar un flujo como el siguiente: generar la orden de compra → enviar a cuentas por pagar → generar ticket visual en una línea de tiempo → programación de pago → Pago

Datos principales

  • proveedor
  • Numero de factura
  • Serie de factura
  • Fecha de emisión
  • Fecha de vencimiento
  • Monto
  • Impuestos
  • Saldo pendiente
  • Moneda
  • Estado del saldo con el proveedor

Estados de las cuentas por pagar

  • Pendiente de pago
  • Parcialmente pagada
  • Pagada
  • Vencida
  • Programada
  • Anulada
